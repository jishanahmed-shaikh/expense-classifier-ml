# Expense Classifier ML

A machine learning pipeline that classifies expense line items into their correct
accounting categories (accountName) from free-text descriptions, vendor identity,
and transaction amounts.

---

## Problem

Given an expense record containing an item name, item description, vendor ID, and
transaction amount, predict which of the **103 accounting categories** it belongs to.

**Dataset:** 4,894 expense records — severe class imbalance (top class: 1,179 samples;
16 classes: 1 sample each).

**Target:** >= 92% overall accuracy on a held-out test set.

---

## Approach

| Feature group | What | Why |
|---|---|---|
| Text (word) | TF-IDF 1-2 word n-grams | Captures keywords like *subscription*, *salary*, *audit fee* |
| Text (char) | TF-IDF 2-4 char n-grams | Handles short / coded descriptions |
| Vendor | One-hot top-200 vendors | ~60% of vendors always map to the same account |
| Amount | Log-amount, quantile bucket, is-negative | Distinguishes expense types by magnitude |

Models evaluated: **Logistic Regression**, **Linear SVC**, **LightGBM (GPU)**.
Best model selected automatically by test accuracy.

## Quickstart

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the notebook

```bash
jupyter notebook notebooks/expense_classifier.ipynb
```

Run all cells from top to bottom. The notebook will:
- Load and explore the dataset
- Engineer features
- Train and compare models
- Print final accuracy and save expense_classifier_model.pkl

### 3. Run inference on new records

```bash
python src/predict.py
```

Or import the function directly:

```python
from src.predict import predict_account

result = predict_account(
    item_name="monthly subscription fee",
    vendor_id="<vendor_id>",
    amount=99.0
)
print(result)
# [('611202 Online Subscription/Tool', None)]
```
