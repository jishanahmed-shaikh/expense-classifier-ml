# CLAUDE.md

Project conventions for Claude Code when working in this repository.

---

## What This Project Does

Classifies expense line items into accounting categories using:
- TF-IDF on item text (word n-grams + char n-grams)
- Vendor one-hot encoding (top-200 vendors)
- Log-transformed transaction amount features
- Linear SVC / Logistic Regression / LightGBM

Dataset: `data/accounts-bills.json` — 4,894 records, 103 classes.
Target: >= 92% overall accuracy.

---

## Variable Naming — Non-Negotiable

Every variable in this codebase uses SCREAMING_SNAKE_CASE. No exceptions.

```python
# right
RANDOM_SEED = 42
TFIDF_WORD_MAX_FEATURES = 15000
X_TRAIN_FULL = hstack([...])

# wrong — do not write this
random_seed = 42
x_train_full = hstack([...])
```

This applies to loop variables, function parameters, local variables, everything.

## Data Path

Always use the constant at the top of the notebook:

```python
DATA_FILE_PATH = '../data/accounts-bills.json'
```

Never use an absolute path. Never inline the filename.

---

## Hard Rules

- `accountId` is never used as a feature — it directly leaks the target label.
- Files in `data/` are read-only.
- `.pkl` and `.joblib` model artifacts are gitignored; regenerate by running the notebook.
- Notebook outputs (cell results) are cleared before every commit.
- No co-author lines, no AI attribution, no "Generated by" in commit messages or code.

---
