# AGENTS.md — reproduce & test

How to set up, run, and verify this project from a clean checkout.

## What it is

A classifier that predicts an expense line item's general-ledger account
(`accountName`) from its text, vendor, and amount. Data: `data/accounts-bills.json`
(4,894 rows, 103 accounts).

## 1. Setup

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Python 3.11+. Pinned versions are in `requirements.txt`.

## 2. Reproduce the full analysis

Runs EDA, trains the model, writes the figures, and prints every metric:

```bash
jupyter nbconvert --to notebook --execute --inplace notebooks/expense_classifier.ipynb
```

Side effects:
- `models/expense_classifier.joblib` — the trained model (git-ignored)
- `reports/figures/*.png` — five figures used by `reports/report.md`

The notebook is deterministic (`RANDOM_SEED = 42`); re-running gives the same numbers.

## 3. Test inference

```bash
python src/predict.py --self-test
```

Expected output (accounts must be non-empty; scores are relative, values will match):

```
  Zoom Workplace Pro monthly                    -> 611202 Online Subscription/Tool  (score 0.03)
  Legal opinion on shareholder matter           -> 617202 Legal Expenses  (score 0.04)
  Recruiter placement fee - senior engineer     -> 617104 Temporary Staff  (score 0.01)
  Office pantry and stationery                  -> 619203 Supplies/Expenses  (score 0.03)
  AWS October usage                             -> 611101 Cloud server - AWS  (score 0.02)
self-test: OK
```

Classify a single item:

```bash
python src/predict.py --item-name "Figma annual subscription" --amount 3000
```

## 4. Expected results

From the notebook's "Results" cell:

| Metric | Value |
|---|---|
| Accuracy — 5-fold stratified CV (primary) | 90.0% (± 0.9) |
| Accuracy — deduplicated 5-fold CV | 89.7% |
| Accuracy — 80/20 stratified hold-out | 92.1% |
| Weighted F1 | 89.8% |
| Macro F1 | 67.3% |

The gap between CV (90.0%) and the hold-out (92.1%) is sampling variation; the CV mean is
the figure to quote. Full discussion in `reports/report.md`.

## 5. Layout

```
notebooks/expense_classifier.ipynb   the analysis, end to end
src/expense_classifier.py            the pipeline (imported by the notebook and predict.py)
src/predict.py                       CLI inference + --self-test
data/accounts-bills.json             raw data — read only, never modify
reports/report.md                    written report
reports/figures/                     figures (regenerated by the notebook)
models/                              trained artifacts — git-ignored
```

## 6. If you change the code

- `accountId` must never become a feature — it is a coded copy of the target and is not
  known at prediction time.
- Keep one notebook. Re-run it end to end before committing so its outputs match.
- Standard PEP 8 naming; constants in `UPPER_SNAKE_CASE`.
- `python src/predict.py --self-test` must still pass.
