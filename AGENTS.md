# AGENTS.md

This file tells AI coding agents (Claude Code, Codex, Cursor, etc.) how this
repository is structured and what conventions to follow when making changes.

---

## Project Overview

**Expense Classifier ML** — classifies expense line items into accounting categories
using TF-IDF text features, vendor one-hot encoding, and gradient boosting.

- Language: Python 3.11
- Primary artifact: 
otebooks/expense_classifier.ipynb
- Dataset: data/accounts-bills.json (4,894 records, 103 classes)

---

## Directory Map

```
notebooks/   Main Jupyter notebook — do not split into multiple notebooks
src/         Standalone Python scripts (inference, utilities)
data/        Raw input data — never modify these files
reports/     Output figures — generated by running the notebook, not hand-edited
```

## Coding Conventions

### Variable Naming
All variables use **SCREAMING_SNAKE_CASE** throughout the codebase.
This is intentional and must be preserved.

```python
# correct
RANDOM_SEED = 42
TFIDF_WORD_MAX_FEATURES = 15000
CLASS_SAMPLE_COUNTS = CLEAN_DF['accountName'].value_counts()

# wrong — do not use
random_seed = 42
tfidf_word_max_features = 15000
class_sample_counts = ...
```

### Constants Block
All tunable hyperparameters and file paths live in the **constants block** near
the top of the notebook (cell 1, after imports). Agents must update values there
rather than hardcoding them deeper in the code.

### Comments
Comments explain *why*, not just *what*. Each logical section has a header block:

```python
# ─────────────────────────────────────────────────────────────────────────────
# SECTION NAME  — one-line explanation of what this block does
# ─────────────────────────────────────────────────────────────────────────────
```

### Data Path
The dataset is always referenced via the constant DATA_FILE_PATH = '../data/accounts-bills.json'.
Never hardcode an absolute path.

---

## Key Constraints

- **Do not use accountId as a feature** — it is a direct foreign key to accountName
  and would cause data leakage.
- **Do not modify files in data/** — the raw dataset is read-only.
- **Do not add co-author or AI-generated commit metadata** to commits.
- **Notebook outputs are not committed** — outputs are cleared before committing.
- Model artifacts (.pkl, .joblib) are gitignored — regenerate by running the notebook.

## Running the Project

```bash
# Install dependencies
pip install -r requirements.txt

# Launch notebook
jupyter notebook notebooks/expense_classifier.ipynb

# Run inference
python src/predict.py
```

---

## Testing Changes

After any code change to the notebook:

1. Restart the kernel and run all cells top-to-bottom
2. Verify the final accuracy cell prints >= 92%
3. Verify no cell raises an exception

There is no separate test suite — the notebook is self-validating.

## Commit Style

Use plain, descriptive commit messages. No AI attribution, no co-authors.

```
feat: add character n-gram TF-IDF features to improve rare-class recall
fix: update data path to use relative ../data/ reference
refactor: extract vendor one-hot builder into reusable function
docs: add per-category F1 breakdown to discussion section
```
